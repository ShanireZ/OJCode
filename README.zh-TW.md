OJCode 是個人線上評測題目程式碼歸檔，以洛谷（Luogu）為主；每個 `.cpp` 檔案都是可獨立編譯的單題解答。

## 線上評測站

- [洛谷 Luogu](https://www.luogu.com.cn/)
- [CodeForces](https://codeforces.com/)
- [LibreOJ](https://loj.ac/)
- [拼題A PTA](https://pintia.cn/)
- [SPOJ](https://www.spoj.com/)
- [AtCoder](https://atcoder.jp/)
- [UVaOJ](https://onlinejudge.org/)

## 目錄與使用

- `Luogu/`、`CodeForces/`、`LOJ/`、`PAT/` 與 `SP UVA AT/` 按評測站收錄題解；檔案名稱通常包含題目編號。
- 沒有統一建置系統或共享測試框架。使用 C++14 編譯器編譯並執行所需的單個檔案，例如 `g++ -std=c++14 path/to/solution.cpp -o solution`。
- 演算法標籤仍在逐步補齊。未標註標籤的舊檔案仍屬於歸檔；收錄不代表在目前評測環境中已驗證通過。

## 貢獻

回報問題或提交修正時註明評測站與題目編號。修改題解時補充演算法標籤，並在提交變更前檢查可用的題目範例。
